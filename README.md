# Мои задачи

Небольшой адаптивный список задач на React, TypeScript и Vite. Добавляйте задачи, отмечайте выполненные, удаляйте их и переключайтесь между фильтрами. Список автоматически сохраняется в `localStorage` браузера.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который Vite покажет в терминале.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Время выполнения

Примерно 45 минут.
